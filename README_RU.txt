ИНВЕНТАРИЗАЦИЯ РЕСТОРАНА — ВЕРСИЯ ДЛЯ iPHONE

Содержимое: мобильное PWA-приложение для Safari, ориентированное на iPhone.
Заведения: Артель, Дафт Паб, На бокальчик, Стекляшка.

ВАЖНО: iPhone не устанавливает полноценное PWA из ZIP/локального HTML напрямую. Для установки на экран «Домой» приложение должно быть размещено по HTTPS-адресу. Сам архив содержит файлы приложения, но не публикует его в интернете автоматически.

ПРОСТОЙ ПУТЬ УСТАНОВКИ:
1. Разместите содержимое папки на статическом HTTPS-хостинге (например, GitHub Pages или другом статическом хостинге).
2. Откройте полученную HTTPS-ссылку в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Откройте приложение с появившейся иконки и один раз загрузите страницу с интернетом, чтобы закэшировались интерфейс и библиотека Excel.
5. После этого интерфейс и импорт XLSX должны работать офлайн, если Safari не очистил данные сайта/кэш. Делайте резервные копии регулярно.

ФУНКЦИИ:
- импорт XLSX/XLS/CSV из iiko на устройстве;
- выбор одного из четырёх заведений и даты;
- сопоставление колонок товара, учётного/фактического остатка, цены;
- расчёт отклонения факт минус учёт, недостачи и излишка;
- локальная история в браузере, экспорт CSV и резервная копия JSON;
- адаптивный интерфейс для iPhone.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ:
- файл обрабатывается локально, данные не отправляются на сервер;
- история хранится в локальном хранилище Safari и не синхронизируется автоматически с компьютером или другими телефонами;
- денежная оценка корректна только если выбраны правильные колонки и цена/сумма в исходной выгрузке;
- формат экспорта iiko нужно проверить на реальном файле пользователя;
- для установки требуется первоначальное размещение на HTTPS-хостинге. Сам по себе ZIP не является установочным файлом iOS.
